Complete Technical Project Overview & Application Flow

Project Brief

SolarCare is a premium, cross-platform management ecosystem designed to streamline interactions between solar installation customers, maintenance technicians, and company administrators. It replaces fragmented workflows with a unified real-time dashboard for issue tracking, AMC (Annual Maintenance Contract) management, and system performance monitoring.

Application Flow

1
Secure Enrollment

Admins register valid customers in a Master list. New users sign up with their email; the backend validates this against the Master list via a PostgreSQL trigger before creating an account.

2
Dashboard Routing

The system detects the user's role (Admin, Technician, Customer) and redirects them to their tailored dashboard using React Router 7.

3
Service Management

Customers raise tickets. Admins assign those tickets to Technicians. Technicians use their mobile app to perform maintenance, upload photos, and close the loop.
